# utxorpc.v1 (unstable)

This version is under construction. Breaking changes are allowed until it is
frozen.

It is listed in `UNSTABLE_VERSIONS` (`.github/workflows/generate.yml`), so
stable releases leave it out of every package. It ships only in next-channel
pre-releases (`vX.Y.Z-next.N` tags), which no registry hands out unless the
consumer asks for that version explicitly. See "Unstable versions and
pre-releases" in the repository README.
